# Odin Recipes

A simple recipes website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## About

This project is an exercise in writing semantic HTML. The goal is not to build something visually polished, but to practise structuring content with the right HTML elements for the right purpose.

## Learning Goals

- Use standard HTML boilerplate correctly across multiple `.html` files
- Structure a page with semantic heading hierarchy (`h1`, `h2`)
- Link between pages using relative paths (`<a href="...">`)
- Embed images with `<img>` and appropriate `alt` text
- Organise content with unordered (`<ul>`) and ordered (`<ol>`) lists
- Understand when to use each list type based on meaning, not appearance

## Project Structure

```
odin-recipes/
├── index.html
└── recipes/
    ├── recipe-one.html
    ├── recipe-two.html
    └── recipe-three.html
```

## Each Recipe Page Includes

- The recipe name as an `h1` heading
- An image of the finished dish
- A description section with a subheading and one or two paragraphs
- An ingredients section with an unordered list
- A steps section with an ordered list
- A navigation link back to the home page

## Notes

Styling is intentionally (mostly) absent. The focus at this stage is on correct and meaningful HTML structure.
